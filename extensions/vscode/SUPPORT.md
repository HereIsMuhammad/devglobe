# Support

Report bugs and request features in the [DevGlobe issue tracker](https://github.com/sajeetharan/devglobe/issues).

Include your VS Code version, operating system, the command you ran, and the complete error message. Do not include credentials, private source code, or personal access tokens.

For security concerns, follow the repository's [security policy](https://github.com/sajeetharan/devglobe/security/policy).
